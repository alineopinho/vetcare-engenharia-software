# VetCare — Engenharia de Software

Repositório independente e complementar ao projeto acadêmico VetCare, dedicado à investigação da implementação existente e à comparação com a documentação original.

Reúne análises, rastreabilidade, diagramas, testes e um laboratório demonstrativo para identificar correspondências, divergências e oportunidades de melhoria.

**Este projeto não substitui o VetCare original nem sua documentação.**

A investigação avança por histórias de usuário, requisitos, regras de negócio e arquitetura, preparando uma base técnica organizada para possíveis evoluções futuras.
